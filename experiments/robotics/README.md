# Robotics Experiment Group

This group provides starter online-RL experiments for Ant, HalfCheetah, Hopper, Walker2d, and Humanoid. Each experiment uses Gymnasium MuJoCo with a Stable-Baselines3 PPO or SAC baseline and an MLP policy. Set `total_timesteps` and the method hyperparameters for your compute budget.

Examples: `python run_pipeline.py robotics/ant_ppo` and `python run_pipeline.py robotics/half_cheetah_sac`. Install the Robotics Suite first so its environment, algorithms, and model dependencies are available.
