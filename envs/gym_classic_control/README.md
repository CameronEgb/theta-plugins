# Gymnasium Classic Control Environment Suite

Canonical classic control benchmark environments for Theta-IDE wrapping standard Gymnasium implementations.

## Included Environments
- **MountainCar** (`MountainCar-v0`): Build momentum to drive an underpowered car up a steep hill.
- **Pendulum** (`Pendulum-v1`): Invert and swing up a continuous torque-controlled pendulum.
- **Acrobot** (`Acrobot-v1`): Swing a 2-link, underactuated planar robot arm above a target line.
